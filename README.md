# Automated Data Cleaning & Validation System

## Project Overview
This project automates data profiling, cleaning, and validation using Python and Pandas.

## Features
- Profiles datasets and identifies missing values.
- Detects potential duplicate records.
- Handles missing and invalid age values.
- Fills missing numerical values using the median.
- Validates age and marks ranges.
- Generates JSON reports for profiling, cleaning, and validation.
- Runs the complete workflow through `main.py`.

## Technologies Used
- Python
- Pandas
- JSON
- Git and GitHub

## Project Structure
- `data/` – Input and cleaned datasets
- `src/` – Profiling, cleaning, and validation modules
- `reports/` – Generated reports
- `main.py` – Runs the complete workflow

## How to Run
1. Install Python.
2. Install Pandas using `pip install pandas`.
3. Open a terminal in the project folder.
4. Run:

```bash
python main.py
```
